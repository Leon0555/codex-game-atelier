# ADR 0001：逻辑模型 Profile 与解析边界

- 状态：Accepted（2026-08-24 Phase 0 审阅通过）
- 日期：2026-08-24
- 决策范围：分发 Agents、Skills 与运行时的模型选择

## 背景

把具体模型 ID 写进提示词、Agent 或 Skill 会把产品正确性绑定到供应方命名、可用性、账号权限和生命周期。不同用户/团队也可能有不同模型清单和策略。开发阶段的模型路由仍然有价值，但不能泄漏为产品依赖。

## 决策

1. 分发内容只声明**逻辑 Profile、能力需求和允许的继承/覆盖**，不包含具体模型 ID。
2. 初始逻辑 Profile 候选：
   - `lead`：范围、综合、所有权和用户沟通。
   - `implementation`：代码与 Godot 实现。
   - `fast-read`：只读探索、资料和日志归纳。
   - `independent-audit`：高风险只读评审。
3. 每个 Profile 可声明能力级别（例如 `standard`、`high`、`critical`）、工具/权限要求和是否允许降级；这些是语义要求，不映射到固定品牌型号。
4. 解析优先级：
   1. 当前用户对本次任务的显式覆盖。
   2. 用户/团队在 Codex 环境中的 Profile 映射。
   3. 当前会话模型继承。
   4. Codex 主机可用的默认解析。
5. `independent-audit`、安全和 release 类任务如果不能满足声明的能力/独立性，不静默降级；返回 `BLOCKED` 或请求用户选择。
6. 用户可以在自己的非分发配置中把逻辑 Profile 映射到具体模型；该映射不提交到模板或发布包。
7. CLI 不选择模型，也不调用模型路由服务；它最多记录逻辑 Profile 和 Codex 主机回报的执行元数据。隐私敏感字段默认不上传。
8. CI 扫描所有分发产物，阻止具体模型 ID 模式进入 prompts、Agents、Skills、模板和运行时代码。仓库内部研发 `AGENTS.md` 可记录开发调度，但必须被分发包排除。

## 备选方案

### A. 固定推荐模型列表

拒绝。短期可复现，但会过期、排除无该模型权限的用户，并把产品与供应方命名耦合。

### B. 完全不声明能力，只继承会话

拒绝。对普通任务简单，但无法表达独立审计、低成本只读探索或高风险任务不得静默降级。

### C. 自建模型注册表/远程解析服务

v1.0 拒绝。它引入网络依赖、维护、遥测/隐私疑虑和隐藏控制面。

## 理由

逻辑 Profile 保留角色与风险语义，同时把具体可用模型的决定留给 Codex 主机和用户。它允许开发团队内部继续使用具体路由，又不会让这些名称变成产品兼容契约。

## 风险

- 不同 Codex 客户端对 Profile/自定义 Agent 配置能力可能不同，Phase 1 必须做兼容性 Spike。
- 过于模糊的能力等级可能导致不一致，需要以可观察行为/验收定义，而非营销词。
- 分发扫描可能误报文档中的示例；应限定发布目录并允许有审计的测试 fixture。

## 迁移与回退

- Profile schema 带版本号；新增字段向后兼容，破坏性变化用 ADR 和迁移器。
- 若某客户端无法解析 Profile，回退为当前会话继承，并明确显示未满足的能力提示；不得偷偷选固定模型。
- 用户覆盖可随时删除，恢复会话/主机默认。

## 验证

- 解析优先级、禁止降级与未知 Profile 的测试矩阵。
- 分发物扫描不含具体模型 ID。
- 至少两个不同用户映射下执行同一 Skill，工作流语义一致。
- 审计任务在能力不足时可复现地阻断而非静默继续。

## Phase 1 实现记录（2026-08-28）

- Plugin Skill 内分发 `capability-profiles.json`，固定 `lead`、`implementation`、`fast-read`、`independent-audit` 四个逻辑 Profile；文件由公开 Schema、解析矩阵和 Plugin 打包器共同验证。
- `owner.logical_profile` 以向后兼容的可选字段进入 task/handoff 公共 Schema，只记录逻辑意图。
- Plugin 不安装用户级或项目级自定义 Agent 配置，也不在 manifest 中虚构 Agent 映射。具体模型和推理设置继续由 Codex 主机的自定义 Agent、用户映射或会话继承承担。
- `independent-audit` 要求 critical 能力和独立只读上下文，任一无法确认即 `BLOCKED`；其他 Profile 能力不足时允许继承，但必须明确披露。
- Plugin 打包验证新增具体模型 ID 扫描与 Profile 语义检查；CLI 仍不选择模型。
