# Security Policy

## Supported versions

Codex Game Atelier has not published v1.0. No preview build, release candidate, branch, archive, or local distribution candidate currently receives a production security-support promise.

After v1.0 is published, this file will identify the supported release line and security-update policy. Historical release candidates will not be supported unless explicitly listed here.

## Reporting a vulnerability

Do not include exploit details, credentials, personal data, or other sensitive material in a public GitHub issue or discussion.

GitHub Private Vulnerability Reporting is the planned private reporting channel for this repository, but it is not enabled yet. Enabling and verifying that remote repository setting is a pre-release action that requires maintainer approval. Until that channel is active, use public issues only for non-sensitive security hardening or documentation problems; do not publish a sensitive vulnerability report publicly.

The project does not request passwords, tokens, Apple signing credentials, Godot account access, or unpublished game assets as part of a vulnerability report.

## Scope

Security reports may cover the Codex Plugin, bundled Go CLI/private runner, Starter Template, file-backed state and evidence handling, explicit optional Git-hook helper, packaging/upgrade/rollback behavior, or release verification. Godot itself, Codex clients, GitHub, and operating-system security controls are upstream products; reports that demonstrate an Atelier integration defect are still in scope.
